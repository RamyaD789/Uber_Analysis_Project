# 🚗 Uber Trip Analysis Dashboard

Welcome to the Uber Trip Analysis Dashboard! This interactive dashboard provides deep insights into ride activity, helping stakeholders track performance, discover patterns, and make data-driven decisions.

---

## 📅 Data Period

**🗓️ June 1st, 2024 – June 30th, 2024**

---

## 🧭 Navigation Guide

The dashboard includes **three main sections**, accessible via the left sidebar:

### 1️⃣ Overview Analysis
- 🔢 KPIs: Total Bookings, Revenue, Distance
- 💳 Bookings by Payment Type
- 🌞🌜 Day vs. Night Trip Analysis
- 🚗 Vehicle Type Performance: 
  - Total Bookings  
  - Total Amount  
  - Average Value  
  - Total Distance
- 📍 Top Pickup & Dropoff Locations
- 📏 Longest Trip Insights
- 📊 Booking distribution by location & vehicle preference

---

### 2️⃣ Time Analysis
- 🕐 Hourly Booking Trends
- 📅 Bookings by Day of the Week
- 🔥 Heatmap: Daily Hourly Booking Volume

---

### 3️⃣ Trip Details
- 🧾 Full trip-level breakdown including:
  - Trip ID
  - Date & Time
  - Vehicle Type
  - Payment Type
  - Passenger Count
  - Distance & Amount
  - Pickup & Dropoff Locations

---

## 📌 Key Metrics Tracked

- 🚘 **Total Bookings**  
- 💰 **Total Booking Amount**  
- 💸 **Average Booking Amount**  
- 🛣️ **Total Trip Distance**  
- 📏 **Average Trip Distance**  
- ⏱️ **Average Trip Time**

---

## 🎮 Interactivity & Filters

- 🧭 **Navigation Sidebar**: Switch between Overview, Time, and Details
- 📅 **Date Range Selector**: Change time period for analysis
- 🌆 **City Filter**: Filter data by specific city (if available)
- 🖱️ **Interactive Visuals**:
  - Click charts to filter data
  - Hover to view tooltips

---

## 💡 Insights You Can Derive

✅ What are the busiest times of day and week?
